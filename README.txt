نسخه استاتیک لندینگ چک الکترونیکی بانک ملت

فایل اصلی: index.html

روش انتشار روی هاست معمولی:
1) تمام محتویات این پوشه را در public_html یا ریشه سایت آپلود کنید.
2) ساختار پوشه‌ها را تغییر ندهید.
3) وب‌سرور به صورت خودکار index.html را نمایش می‌دهد.

این نسخه به Node.js / Next.js / Vinext نیاز ندارد و از HTML/CSS/JavaScript معمولی استفاده می‌کند.
